# Multilease Excavation concept website

Concept demo site prepared for Multilease Excavation Pty Ltd (Sydney demolition and excavation) by Mago Labs. Not the live site.

- Static site: `index.html` plus four service pages, media in `media/`
- `_build/`: the generator (`build.py`, `services.py`, `styles.css`, `site.js`). Run `python3 _build/build.py` from a folder where `../site` is the output, or adjust `OUT` in `build.py`.
- Deploys as a plain static site on Vercel (no build step).
